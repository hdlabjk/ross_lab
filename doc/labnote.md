# AMD Ross™ Agentic AI Assistant for Faster Development チュートリアルデモセッション



AMD Ross™ Agentic AI Assistantによって、FPGAデザイン能力を拡張できます。大量のドキュメントを読み、ツールのコマンドに慣れる時間から解放され、デザイン作業の初日から長年の経験者と肩を並べて作業することができます。

AMDのドキュメントを優先的に検索することで、正しい答えに直接たどり着くことができます。AMD Rossは、AMDのツールを直接駆動し、エラーがあった場合には、ドキュメントを再検索し自主的にエラーを解決します。

ここでは６つのlabを準備しました。

1. チャットを使いデザインの方法論、用語、概念を理解する。
2. 自然言語で書かれたARM core を利用するシステムのスペックからブロックダイアグラムとRTLを作成する。作成したデザインの問題を解析し、解決案を作成し、スペックを更新する。
3. RTLの構造的な問題を解析し、問題解決に導く。１か所でしか使われないレジスタの名前がタイプミスの可能性、デザインが未完である可能性を調べる。
4. ユーザがデザインしたテストベンチを使いAXIマスタのテストを行い、プロトコル違反を発見する。プロトコルの検証は自動的に行われ、ユーザはそのための検証コードを書く必要は無い。プロトコル違反を起こした原因を特定し、RTLを修正する。
5. デザインのタイミング検証を行い、問題点を特定する。タイミング目標未達の原因になるデザインの致命的な問題を見つけ、その解決案を検討する。
6. デザインのタイミング検証を行い、問題点を特定する。データストリームの問題を解決するためにどのようなツールのオプションが使えるのか分析する。

labの実行には以下のものが必要です。

- Vivado ML 本日は2025.2 を使用します。2026.1.1, 2025.1, 2024.X も利用できるはずです。
- AMD Vivado MCPサーバーとクライアント。AMDサイトからダウンロードします。Windows, Linux 共用で、ライセンス等は不要です。
- AMD Knowledge。AMDのドキュメントに特化したチャット。クラウド上で実行されます。MCPサーバが利用しますが、単体でも利用できます。単体で利用する時は、webブラウザだけで追加ツールのインストール、ライセンス、登録は要りません。
- 自然言語入力のためのCLI と、LLM。現在流通しているLLM であればどれでも使えます。クラウド上でも、ローカルでもMCP サーバに接続できるものであれば利用できます。本日は、VSCode + "GitHub Copilot+"を使います。**GitHub Copilot+**のライセンスは有料です。GitHub Coplit+はMicroSoft Office Copilot+は別製品です。

## Lab3　RTLのリント
